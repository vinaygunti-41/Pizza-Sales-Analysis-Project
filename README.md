# 🍕 Project Overview

The **Pizza Sales Analysis Dashboard** is a Business Intelligence project that analyzes restaurant sales data to understand **customer purchasing behavior, revenue performance, pizza popularity, sales trends, and inventory planning**.

Using **Power BI, Excel, and python**, this dashboard converts transaction-level sales data into actionable insights that help restaurant owners improve sales, staffing, and marketing strategies.

> 🎯 **Goal:** Transform raw pizza sales data into interactive business insights for smarter decision-making.

---

# 🎯 Business Objectives

This project answers important business questions such as:

* 💰 What is the total revenue generated?
* 🍕 How many pizzas were sold?
* 🧾 How many customer orders were placed?
* 📈 Which pizzas generate the highest revenue?
* 📉 Which pizzas perform the worst?
* ⏰ When are peak order hours?
* 📅 Which days and months generate the most sales?
* 📦 Which pizza categories and sizes are most popular?

### 📋 Key Dataset Fields

| ---------------- | -------------------------------------------- |
| `order_id`       | Unique Order ID                              |
| `pizza_id`       | Pizza Identifier                             |

# 🧹 Data Cleaning Process

Before building the dashboard, the dataset was cleaned using Excel and SQL.

### ✔️ Cleaning Steps

* Removed duplicate transactions.
* Handled missing values.
* Corrected date & time formats.
* Standardized pizza category names.
* Created calculated columns.
* Verified quantity and revenue values.
